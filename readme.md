# GeoFS-V4.0_Autothrottle

An experimental GeoFS V4 port of the V3.9 Autothrottle. Use **A/THR** in the native autopilot bar to control selected speed in KTS or Mach and arm Landing Mode. The V3.9 PID controller, reverse thrust behavior, and optional Overpowered Engines integration are carried over.

Install with a userscript manager and reload GeoFS 4.0 Beta. Core Library and Design System load as dependencies. The native autopilot and A/THR cannot control throttle simultaneously.

**Version 0.1.4 is unstable and has not been flight-tested on GeoFS V4.** Controller response, landing behavior, and compatibility with other scripts need live validation.
